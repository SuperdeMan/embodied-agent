# embodied-agent

跨本体的具身智能体运行时（embodied agent runtime）——「大脑—小脑—本体」分层架构：LLM/VLM 负责认知规划（System 2），技能策略负责闭环执行（System 1），硬件抽象层隔离本体，安全监督、数据引擎、可观测三条竖切贯穿。初始场景：**桌面操作机器人（低成本机械臂 + 语音全双工交互）**，仿真先行、真机跟进。

> 当前状态：**M0 · 设计与规范阶段**（2026-08）。本仓库现为架构文档 + 项目规范，代码骨架按路线图落地。

## 设计原则（一分钟版）

1. **接口高于实现**：LLM、VLA 策略、语音、感知、仿真器、本体全部 provider 化——模型半年一换代，押注可换模型的接口，不押注任何单一模型。
2. **数据一等公民**：每次运行默认产出训练级 episode，格式对齐 LeRobotDataset；私有场景数据与版本化评测集是护城河，代码不是。
3. **安全独立通道**：LLM 只出计划，确定性执行器执行，执行后验证世界状态；四级安全防线不依赖任何 AI 输出的正确性。
4. **仿真先行**：一切能力先在 MuJoCo 闭环并建立评测基线，再上真机（SO-101）。

## 路线图一览

| 阶段 | 主题 | 退出标准（一句话） |
|---|---|---|
| M0 | 规范与骨架 | 文档齐备，代码骨架 + car-agent 复用移植完成，CI 绿 |
| M1 | 仿真闭环 | 语音指令在仿真中完成 pick/place 全链路，运行即产数据 |
| M2 | 学习闭环 | 首个学习策略不劣于脚本技能，训练→部署一条命令 |
| M3 | 真机落地 | SO-101 真机复现仿真闭环，安全防线全部生效 |
| M4 | VLA 与泛化 | 微调 VLA 接管 ≥2 个技能，未见任务组合可测泛化 |
| M5 | 数据飞轮 | 周级「数据→训练→评测→部署」自动循环，第二本体接入 ≤2 周 |

## 与 car-agent 的关系

同作者的智能座舱 multi-agent 系统（云-边协同、语音全双工、LLM 规划 + 确定性执行）。本项目继承其经过 ~4000 个测试验证的工程资产与安全方法论，并泛化到物理本体：座舱 agent 是「固定场景内的多模态交互 + 受约束动作空间」，桌面具身是它的自然延伸。两仓库零运行时依赖（复制改造制，详见复用评估文档）。
