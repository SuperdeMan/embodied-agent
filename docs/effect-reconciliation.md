# 持久效果证据 · D024

> 2026-11-04，参考范围已验收，应用 `5e2311f` 已部署私网云端；数据卷保留与实际激活证据单独记录。

调用结果、效果证据和停止状态分别表达。效果使用 SAT/UNSAT/UNKNOWN，不把状态观察变成调用成功或停止证明。绑定本体的 Registry 在本次资源释放前采样 manifest 声明的空间谓词，结果先追加持久事件，再交给执行器判断依赖。未知调用且未确认停止时只记 UNKNOWN。

放置技能由旧结构校验升级为空间效果校验；`$input:held_object` 在准入时由受信本体快照绑定并进入证据摘要，不能拿 handler 返回的任意对象冒充放置目标。旧版本同 ID 的请求声明摘要若不兼容，会拒绝重放；历史调用仍可查询，不追溯改写。

证据保存操作/尝试、请求摘要、验证声明摘要、控制器和观察 boot、场景/profile、时间、源和有限值快照。历史事件带完整性摘要，存储损坏或身份不符时不提供可用证据。当前资格窗口为 2 秒本机墙钟；RPC 以服务端证据年龄加客户端 RTT 保守检查。新操作占用冲突资源、reset、控制器重启或 profile 改变均使旧证据失去当前资格。

旧 operation_id 的调用回放只返回历史结果，不重新采样为旧动作补成功。普通查询只取历史事件；显式效果重查不写动作，要求无活跃/隔离资源、旧 worker 已退出且场景与资源序列仍匹配。UNKNOWN 操作必须先按 D021 确认停止，再重查效果；即使观察 SAT，原调用仍 UNKNOWN，不释放旧依赖或自动重放。

无本体绑定或无 `state_predicate` 的参考技能保留原验证路径。旧版本缺少声明/场景元数据的历史操作无法凭新配置补证。单次效果采样不代替完整任务生命周期与多次尝试调度；硬件场景和跨机视觉证据尚待单独实现。

查询 `embodied operation --remote HOST:PORT --id OPERATION_ID` 返回历史效果事件。显式只读重查使用 `--reconcile-effect --attempt ATTEMPT_ID`；它不属于模型工具目录，不需要动作确认，但所有上下文/停止/资源条件仍由接收端检查。D021 的 `--reconcile-stop --confirm` 保留独立确认门。

调用结果提交与效果事件为顺序事务：结果已提交而效果写入失败时，调用历史仍保留，执行器收到失败且不释放后继；重启回放缺失证据时为 UNKNOWN。只读查询不隐式补证。语义效果还须满足 D023 原对象期限与当前相机标定，不能单靠新的效果记录时间续期。同步提供方阻塞仍需后续 worker 隔离，不宣称硬实时采样。
