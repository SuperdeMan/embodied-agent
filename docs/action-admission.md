# 统一动作准入与遥操作 · D022

> 2026-11-03，实施中；不自动更新云端已验收应用。

## 控制链

Registry 是同一仿真实例的执行权威。脚本、策略与手动命令先经过参数、确认、持久操作和资源准入，再持有带身份的 InvocationPermit。低层 ActionEnvelope 是可检查的数据，不是授权凭据；驱动还检查许可是否由绑定的运行时发出、是否仍活跃并占有完整资源。

包络固定本体、控制器 boot、场景 epoch、profile、运行时 boot、operation/attempt、lease epoch、sequence、source、joint order、joint-position 模式、rad 单位、gripper normalized-position 语义、反馈引用与期限。重复/倒退序号、旧实例、旧场景、不匹配的布局、伪造反馈和过期数据都拒绝，不自动改成当前值。

运动原语每次写入取得新鲜本体反馈；学习策略沿用生成该动作块的输入快照引用，慢推理不能借写入口重新盖时间戳。当前参考预算为命令最长 1 秒、输入反馈最长 2 秒墙钟，仍受技能总期限约束；这些不是硬实时或真机停止时延保证。

## 遥操作与维护

每条 jog/gripper/home 命令以独立操作经过同一个账本和组合资源仲裁。冲突立即拒绝，不抢占正在执行的技能，不清除未知隔离。遥操作方法保留同步调用形式，但只在控制运行时所属线程准入；物理技能工作线程只负责持许可执行。

episode reset 与录制钩子更改必须在控制器空闲时完成。已绑定实例不能用裸 write 或第二 Registry 绕过；场景 reset 不改变活跃操作的代次，也不删除历史账本。空闲模拟时钟可推进物理，但不能生成新目标；携带撤销/过期许可的迟到线程仍被阻断。

## 证据边界

保留原有 Guard、D021 停止围栏和确认门。动作包络准入失败不会被技能自报 OK 掩盖，发生潜在副作用后仍以 UNKNOWN 留证、隔离资源。操作来源和身份写入已有事件，不改变训练数组的字段布局。

当前没有跨主机 raw-action API、设备认证签名、语义对象 TTL 或完整碰撞检查。Python 代码直接篡改 native data 不属于受支持入口；发布与插件仍需受信代码边界。原 reference 夹具不代表绑定后的平台入口已获权限。
