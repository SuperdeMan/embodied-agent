# 有界只读观察 · D025

> 2026-11-04，实施中。默认等待预算 1 秒；原对象/效果 2 秒有效期保持。

Registry 的观察通道最多一个在途工作，不排队、不在超时后自动换线程。异步调用者超时或取消立即退出等待，后台线程继续被追踪；迟到数据不再落账。观察工作使用独立上下文，不能继承 InvocationPermit，也不能通过驱动 write/step/reset 产生动作。

放置准入先持久记录意图和未完成绑定，再异步读取持有对象；有效绑定追加事件后才进入 handler。绑定超时不执行动作；效果采样超时保存 UNKNOWN，保持原调用结果。效果重查或资格检查超时不能复用旧 SAT。所有 SQLite 操作在运行时所属线程完成。

在途观察尚未实际退出时，新观察、新动作、reset、停止对账和关闭运行时都拒绝。只读查询、取消与监督心跳应持续响应。已完成调用在效果采样阶段收到取消，不改成未知物理调用，也不把已知结果掩盖为成功效果；其效果记为未知，线程结束后才恢复新请求准入。

历史回执读取先于观察忙碌检查，因此不会把已执行旧操作误报为新的拒绝或重新执行。渲染在途状态也作为新动作/reset 的前置屏障，防止事件循环等待被渲染线程占用的原生锁；普通有界观察仍可在独立读线程等待该锁，超时后继续保留实际工作状态。

对于正常预览帧，最多一个新动作准入请求可异步等待当前帧，等待上限同为 1 秒；期间不启动替代预览帧。等待阶段可取消/Halt，尚未执行动作或写入调用意图；超时后返回忙，不进入 handler。浏览器改为上一帧完成后再轮询，避免每 200 ms 改写图片 URL、反复中止慢帧。冷启动首帧可能返回 503，验收在独立的 6 秒就绪窗口内有限重试，不放宽单帧预算。

应用世界状态与 RPC 状态读取使用同一有界入口；控制台渲染单独保留具有 GL 线程亲和性的单任务通道，拒绝排队并限制等待。同步 Python 兼容接口保留，但控制台和 RPC 使用异步路径。

线程不能安全强杀；观察可能持有提供方/原生锁或 GIL，因此本批不保证强制回收、原生故障隔离或进程退出时限。永久卡住时需要受控重启，不能在同一进程无限启动替代 worker。无数据库迁移、无新跨机时钟协议。
