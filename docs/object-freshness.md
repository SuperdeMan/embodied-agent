# 对象级感知时效 · D023

> 2026-11-04，实施中；验收结果按实际功能提交记录。

对象缓存保留最后真实检测的相机、序号、采集墙钟与仿真时刻、场景和标定摘要。每次读取仍获取当前本体反馈，但不修改对象检测年龄。附着推算标注 `kinematic`，沿用同一次检测的期限；只有新的有效检测可以续期。

初始参考预算为 2 秒仿真时间和 2 秒本机 monotonic，任一到期就移除对象；两者覆盖快速模拟和物理时钟暂停的失联。该预算覆盖现有最长单段 1.5 秒运动及其稳定窗口，不是跨本体通用保证。新视觉结果以采集开始时刻计龄，不以模型返回时刻计龄。

所有对象期限由受信包装器配置。相机失败保留仍在期限内的最后证据，超期即未知；错误不能刷新检测时间或自动续命。场景重置、底层绕过包装器的代次变化、仿真时间倒退和相机内外参变化都使缓存失效。渲染/检测跨代次结果不得提交。原始裁判真值不作为视觉失败后备。

规划上下文和世界状态只列可用对象，保留证据用于后续 TTL 检查。效果谓词在缺失或过期时返回 UNKNOWN，阻断依赖该效果的后继。脚本在对象目标求解后、运动段开始前检查原始目标证据，慢逆解不能沿用过期坐标；已接受的短段关节插值继续受 D022 约束，不宣称完整动态避障。策略输入不接受缺失语义对象，每次输出检查原输入对象证据，推理后读取新本体反馈不会刷新它。

本批不改 RPC wire、操作数据库或云端部署。D019 仍只发布即时仿真真值；D022 的本体反馈期限、动作期限和 Guardian 独立存在。有限期的附着推算仍是原参考模型的几何信念，不能当成真实夹持或碰撞安全证明。下一批为任务效果持久对账。
